How do you change and check the LACP system priority and the LACP port priority? Where is each configured?	<b>System priority</b> (global): <code>lacp system-priority 1</code>, check with <code>show lacp sys-id</code> (e.g. <code>1, 0062.ec9d.c500</code>). Default 32768, lower wins = primary switch.<br><b>Port priority</b> (member interface): <code>lacp port-priority 1</code>. Lower = preferred to be active when max-bundle limits the members; the others go Hot-standby (H).	ENCOR ch05 LACP advanced
Which settings must match on every member interface of an EtherChannel?	Port type (all L2 switchports or all L3 routed), port mode (all access or all trunk), native VLAN, allowed VLANs, speed, duplex, MTU (L3), load interval, storm control.<br>Rule: set the port type on the members, bundle them, then do all other config on the <b>port-channel interface</b>.	ENCOR ch05 EtherChannel troubleshoot
An EtherChannel won't form. Besides matching settings, what else do you check?	1. Each member link goes between the <b>same two devices</b> only.<br>2. All member ports are active (not shut).<br>3. Modes can negotiate: both <b>on</b>, or LACP with at least one side <b>active</b>, or PAgP with at least one side <b>desirable</b>.<br>4. Members configured the same (LACP port priority may differ).<br>5. LACP/PAgP packets sent <b>and</b> received on both sides (counters).	ENCOR ch05 EtherChannel troubleshoot
Does an EtherChannel send packets round-robin across its links? How is the link chosen, and which command sets it?	No. A <b>hash</b> of header fields picks the link, so one flow always uses the same member.<br>Global (system-wide) command: <code>port-channel load-balance <i>hash</i></code>, e.g. <code>src-dst-ip</code>, <code>src-dst-mac</code>, <code>src-dst-mixed-ip-port</code>.<br>Check it with <code>show etherchannel load-balance</code>.	ENCOR ch05 EtherChannel load-balancing
A port channel goes to a router and one member link carries almost all the traffic. Why, and what's the fix?	A MAC-based hash: the router's MAC is always the same source/destination, so the hash keeps choosing the same link.<br>Fix: hash on <b>source/destination IP</b> or on <b>TCP/UDP ports</b> instead.	ENCOR ch05 EtherChannel load-balancing
Why should an EtherChannel have 2, 4 or 8 members, and how do you see how evenly the links are loaded?	The hash is binary, so powers of two spread traffic evenly; a <b>3-link</b> bundle balances worse than 2 or 4 (another reason to use <code>lacp max-bundle</code>).<br>Per-link load: <code>show etherchannel port</code>, the <b>Load</b> field (in hex).
