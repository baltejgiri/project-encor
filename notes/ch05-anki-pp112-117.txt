Which command shows the LACP neighbor's system ID, system priority and fast/slow LACPDU flag? Which shows your own LACP system ID?	<code>show lacp neighbor [detail]</code>: neighbor system ID, priority, flags (S = slow, F = fast, A = active, P = passive).<br><code>show lacp sys-id</code>: local system priority + MAC. Used to confirm all members connect to the <b>same</b> device.	ENCOR ch05 LACP verify
How do you check that LACP packets are actually being exchanged on each member link? What does a problem look like?	<code>show lacp counters</code> (PAgP: <code>show pagp counters</code>). Sent and Recv should both increase over time.<br>Sent increasing but <b>Recv stuck at 0</b> = physical problem or bad/incompatible config on the far end; check the remote's counters.<br>Reset with <code>clear lacp counters</code>.	ENCOR ch05 LACP troubleshoot
LACP fast vs normal: hello interval, failure-detection time, the command, and the rule for both sides?	Normal: LACPDU every <b>30 s</b>, link dropped after 3 missed = up to <b>90 s</b> loss.<br>Fast: every <b>1 s</b>, removed in <b>3 s</b>.<br>Member interface command: <code>lacp rate fast</code>. Both switches should match (all fast or all slow). <code>show lacp internal</code> flag F = fast.	ENCOR ch05 LACP advanced
What does <code>port-channel min-links 2</code> do, where is it configured, and what flag shows when it isn't met?	Configured on the <b>port-channel interface</b>. The port channel stays down until at least 2 members are bundled (default: up with just 1).<br>Log: <code>%ETC-5-MINLINKS_NOTMET</code>; summary flag <b>M</b> = not in use, minimum links not met (e.g. Po1(SM)).<br>Only needed on one side, but set both for easier troubleshooting.	ENCOR ch05 LACP advanced
What does <code>lacp max-bundle</code> do, why use it, and what happens to the extra links?	Port-channel interface command that caps active members (e.g. powers of two: 2, 4, 8, so the load-balancing hash spreads evenly).<br>Extra members become <b>Hot-standby</b> (flag <b>H</b>) and take over if an active one fails.<br>Only required on the primary switch; set both for clarity.	ENCOR ch05 LACP advanced
With more members than max-bundle allows, who decides which links are active, and how?	The <b>primary switch</b> = the one with the lower <b>LACP system priority</b> (tie: lower system MAC).<br>It picks members by <b>LACP port priority</b> (lower wins; default 32768), then the lower interface number.
