Give the interface command for each EtherChannel type: static, LACP and PAgP.	<b>Static:</b> <code>channel-group 1 mode on</code><br><b>LACP:</b> <code>channel-group 1 mode {active | passive}</code><br><b>PAgP:</b> <code>channel-group 1 mode {auto | desirable} [non-silent]</code>	ENCOR ch05 EtherChannel
PAgP: what is silent mode (the default), and when should you add <code>non-silent</code>?	<b>Silent</b> (default): the port can form an EtherChannel with a device that isn't PAgP-capable and rarely sends packets.<br><b>non-silent</b>: the port must receive PAgP packets before it joins. Recommended between two PAgP switches: the link comes up faster.	ENCOR ch05 EtherChannel PAgP
Where do EtherChannel settings go, and what decides whether the bundle is Layer 2 or Layer 3?	Settings (e.g. <code>switchport mode trunk</code>) go on the <b>port-channel interface</b>.<br>The <b>member interfaces' mode</b> decides L2 or L3: set <code>no switchport</code> on the members <i>before</i> adding them for a Layer 3 bundle.	ENCOR ch05 EtherChannel
In <code>show etherchannel summary</code>, what status should a healthy port-channel show, and what do the letters mean?	<b>SU</b>: <b>S</b> = Layer 2 (R = Layer 3), <b>U</b> = in use / working. <b>D</b> = down.<br>The codes are case-sensitive.	ENCOR ch05 EtherChannel verify
Port-channel status <b>M</b> in <code>show etherchannel summary</code>: what does it mean, and which command causes it?	At least one LACP adjacency is up, but fewer member links are active than the configured minimum, so <b>no traffic is forwarded</b>.<br>Caused by <code>port-channel min-links N</code> on the port-channel interface.	ENCOR ch05 EtherChannel verify
Member interface flags in <code>show etherchannel summary</code>: what do <b>P</b>, <b>H</b>, <b>I</b> and <b>s</b> mean?	<b>P</b>: bundled, forwarding.<br><b>H</b>: hot standby, not forwarding (LACP, <code>lacp max-bundle</code> reached).<br><b>I</b>: individual / stand-alone, no LACP heard.<br><b>s</b>: suspended.	ENCOR ch05 EtherChannel verify
What does <code>show interfaces port-channel 1</code> show about bandwidth, and why does it matter?	BW is the <b>total of all active members</b> (two 1 Gbps links = 2,000,000 Kbit/s) plus the member list.<br>Anything that uses bandwidth (QoS policies, routing protocol costs) adjusts when a member goes up or down.	ENCOR ch05 EtherChannel verify
Which command shows LACP/PAgP details for each member port, including the partner's info?	<code>show etherchannel port</code>: mode (Active, Desirable-Sl), protocol, flags (F = fast LACPDUs, S = slow, A = active, P = passive), port priority (default 32768), and the partner's device ID. Useful for spotting config mismatches.	ENCOR ch05 EtherChannel verify
