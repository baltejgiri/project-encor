# Project Overview

CCNP Enterprise Exam Prep 2026 - 2027 project includes two cisco exams named "350-401 ENCOR" and "300-410 ENARSI". These two exams are next step in the career growth after passing the CCNA Enterprise Exam. The overall timeframe for both exams is 1 year, starting May 24 2026. These certificates will be called CCNP Enterprise once both certifications ENCOR and ENARSI are passed. A full progress report will be analyzed by Claude Code to help with keeping the project on track.

Use project_instructions.md file for details.
Use project_chapters_list.md file for details what chapters the exam is covering.
